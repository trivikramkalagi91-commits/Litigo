Part 1: Judge Q&A
CRITICAL Q1 "Is Litigo just adding text to the prompt?"
❌ NO! Prompt modification is only Layer 1 of 4. Litigo's real innovation is Layer 2 & Layer 3: a local WebAssembly vector engine (Moss WASM) running in browser memory.

As LLMs stream output tokens, Litigo's content script intercepts DOM mutations, computes 128-dimensional vector embeddings, and executes matrix dot-product cosine similarity queries in sub-3ms P50 latency with 0 server costs.
